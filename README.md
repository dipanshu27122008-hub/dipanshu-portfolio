# Dipanshu Kumar — Developer Portfolio

A responsive personal developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Upload all four files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.
5. Visit `https://dipanshu27122008-hub.github.io/dipanshu-portfolio/` after deployment completes.

## Customize
Update the project links and profile details in `index.html`. Styling is in `style.css`; mobile navigation is in `script.js`.
